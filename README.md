# Fitness and Health Tracking Analysis | Power BI

##  Project Overview

The Fitness and Health Tracking Analysis project explores physical activity, workout duration, recorded calories burned, sleep patterns, dietary preferences, and demographic characteristics using Power BI.

The project aims to transform fitness and lifestyle data into meaningful insights through interactive visualisations, key performance indicators (KPIs), and comparisons across demographic groups.

##  Project Objectives

- Analyse daily physical activity using recorded step counts and activity categories.
- Examine workout duration and recorded calorie expenditure.
- Explore sleep duration and its relationship with physical activity indicators.
- Compare fitness patterns across age groups and gender categories.
- Investigate recorded dietary preferences.
- Develop interactive visualisations to communicate findings clearly.

## Data Quality and Limitations

The dataset was reviewed for missing values and duplicate records.

The source and provenance of the dataset have not been independently verified. Consequently, the results should be interpreted as descriptive observations from the supplied dataset rather than representative population statistics.

Recorded calorie expenditure should not be treated as a clinically verified measurement. The unit used for workout duration should also be confirmed before interpreting it as minutes.

The dataset does not support conclusions about causation or changes over time.

##  Project Purpose

This project demonstrates the application of Power BI to fitness and lifestyle data, with a focus on interactive reporting, exploratory analysis, KPI development, and communicating data-driven insights.
